# Homebrew tap for Passage

```
brew tap mrgluek/passage
brew trust mrgluek/passage
brew install --cask passage      # the macOS app
brew install passage-cli         # command line, macOS and Linux
```

Newer Homebrew versions load third-party taps only after `brew trust`.
Files come from the Passage releases. Passage: <https://passage.gluek.info>
